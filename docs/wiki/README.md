# Project wiki

Plain-language guide to the project, for the team. No prior knowledge assumed. Updated every working day at about
18:00 with that day's results.

| Page | What's in it |
|---|---|
| [Status](status.md) | Where each experiment stands, the results so far, and a short diary of what changed each day |
| [FAQ](faq.md) | The questions you'd ask (or get asked in the presentation), answered simply |
| [Glossary](glossary.md) | Every piece of jargon in the repo, in one or two sentences |

The detailed, technical record lives elsewhere: designs in [`docs/`](..), measured results in
[`results/`](../../results), decisions and why we made them in [`docs/decisions.md`](../decisions.md). The wiki
explains; those files are the evidence. If the wiki and those files ever disagree, the files win.
